# От кода до публичной игры: пошаговый гайд (Windows)

Требования Roblox к публикации сверены с официальной документацией в ноябре 2026: [Publish games and places](https://create.roblox.com/docs/production/publishing/publish-games-and-places), [Kids and Select](https://create.roblox.com/docs/production/publishing/kids-and-select). Правила часто меняются. Если меню в Studio выглядит иначе, сверься с этими страницами.

---

## Шаг 1. Войти в папку репозитория

Папка репозитория — это папка, где лежат `default.project.json`, `rokit.toml`, `src`. Все команды ниже выполняются в ней.

**Вариант А — терминал IntelliJ (проще всего).** File → Open → выбери папку репозитория. Внизу вкладка **Terminal** уже открыта в нужной папке.

**Вариант Б — PowerShell.** Обычный, не от администратора:
```powershell
cd "D:\programming\projects\2.IntelliJ_IDEA\Java\roblox"
git status
```
Что может ответить `git status`:
- `On branch ...` — ты в репозитории, переходи к шагу 2;
- `not a git repository` — в папке нет клона, сделай пункт ниже.

**Если клона нет.** Склонируй репозиторий; GitHub попросит войти через браузер:
```powershell
cd "D:\programming\projects\2.IntelliJ_IDEA\Java"
git clone https://github.com/covest2051/roblox.git roblox-game
cd roblox-game
```
Новое имя `roblox-game` — на случай, если старая папка `roblox` не пустая.

## Шаг 2. Получить код игры
```powershell
git fetch origin
git checkout claude/roblox-game-concepts-setup-tfp5ox
git pull
```

## Шаг 3. Инструменты (один раз)
1. Если `rokit --version` не находится, открой **новое** окно PowerShell или перезагрузи компьютер: установщик Rokit дописал PATH.
2. В папке репозитория:
   ```powershell
   rokit install
   rojo plugin install
   ```
   На вопрос о доверии инструментам отвечай `y`.
3. Проверка: `rojo --version` должен показать `Rojo 7.7.1`.

## Шаг 4. Первый запуск в Studio
```powershell
rojo build -o game.rbxl
```
1. Открой Roblox Studio → **File → Open from File** → `game.rbxl`.
2. Включи **View → Output**.
3. Нажми **Play** (F5).
4. Пройди [`PLAYTEST.md`](PLAYTEST.md) и отправь отзыв по шаблону оттуда.

## Шаг 5. Цикл «исправили → проверили»
Пока идут правки:
- скачай исправления: `git pull`;
- собери заново: `rojo build -o game.rbxl`;
- открой файл заново и нажми Play.

Чтобы не переоткрывать файл каждый раз: открой `game.rbxl`, в PowerShell запусти `rojo serve` и не закрывай окно, в Studio нажми **Plugins → Rojo → Connect**. Тогда после `git pull` код сразу обновится в Studio.

## Шаг 6. Подготовка к публикации

### Аккаунт
- [ ] Аккаунту Roblox **не меньше 2 дней**.
- [ ] Пройдена **проверка возраста** (age check):
  - roblox.com → ⚙ **Settings** → **Account Info** → подтверждение возраста;
  - способ — оценка возраста по лицу (селфи) или документ;
  - если ещё не прошёл, Studio попросит это при публикации.
- [ ] Включена **двухэтапная проверка** (Settings → Security). Для аудитории 16+ необязательна, но защищает аккаунт.

### Материалы страницы игры
- [ ] **Иконка:** квадрат, минимум **512×512**. Можно сделать скриншот в Studio (кадр с палаткой или избой) и обрезать до квадрата.
- [ ] **Скриншоты:** **16:9**, лучше **1920×1080**, до 3 МБ, можно до 10 штук. Хорошие кадры:
  - палатка в метели;
  - вешки на склоне;
  - костёр под кедром;
  - «огни в небе»;
  - ручей подо льдом;
  - изба.

  Как снять: Play → встать в нужном месте → скриншот экрана. Интерфейс можно скрыть через DBG → God mode и подходящий ракурс.
- [ ] **Название и описание** — готовые варианты ниже.

**Название** (рекомендую без фамилии в заголовке, узнаваемость даёт описание): `The Pass: Ural Blizzard` или `Перевал: Буран`.

**Описание (RU):**
> Северный Урал, февраль. Твоя группа идёт маршрутом туристов 1959 года через Перевал Дятлова. Ночью начинается буран, и палатку заваливает снегом. Возьми 3 вещи из 5, разрежь стенку и доберись до избы, пока не замёрз. Прячься от порывов ветра за камнями, собирай хворост, разводи костры, переходи ручей по тонкому льду. Один уровень на 10–15 минут. События игры вымышлены.

**Description (EN):**
> Northern Urals, February. Your group follows the 1959 route through Dyatlov Pass. A blizzard hits at night and buries your tent. Grab 3 of 5 items, cut your way out and reach the hut before you freeze: shelter from gusts behind rocks, gather firewood, light fires and cross the creek on thin ice. One 10–15 minute level. The events of this game are fictional.

**Жанр:** Survival.

### Рельеф: «запечь» перед публикацией (рекомендую)
Иначе каждый новый сервер 5–15 секунд строит рельеф.
1. Открой place в Studio в режиме редактирования (не Play).
2. **View → Command Bar**, вставь и нажми Enter:
   ```lua
   require(game.ServerScriptService.Server.World).bakeTerrain()
   ```
3. Подожди, пока появится рельеф, и сохрани (Ctrl+S).

## Шаг 7. Первая публикация (пока приватно)
1. В Studio с открытым `game.rbxl`: **File → Publish** (первый раз откроется окно Game details).
2. Загрузи иконку и скриншоты, впиши название, жанр, описание → **Save**.

Игра теперь в облаке, но видна только тебе. Дальше:
- проверь её в настоящем клиенте: Creator Hub (create.roblox.com → Creations) → игра → открыть страницу → **Play**;
- в настройках мест (Places) задай размер сервера, например **6 игроков**;
- по желанию позови до 10 друзей: **File → Invite early testers**.

**С этого момента работай с облачным place, а не с `game.rbxl`.** Creator Hub → игра → Places → **Edit in Studio** → `rojo serve` → Rojo **Connect**. Код подтягивается из репозитория, публикуется через **File → Publish**.

## Шаг 8. Открыть игру для всех (16+, бесплатно)
1. В Studio: **File → Publish** → **Continue**.
2. Первый вопрос анкеты Maturity & Compliance — есть ли в игре контент «только для взрослых» (age-restricted). В «Перевале» его нет: нет жестокого насилия, крови, алкоголя, романтики, мата. Отвечай **No** → **Publish**.
3. Игра получает метку **Content May Vary** и становится доступна игрокам **16+**, прошедшим проверку возраста.
4. Creator Hub → игра → **Publish settings → Manage Audience** → **Manage access** → вкладка **Public**: переключатель **Friends** выключен (иначе играть смогут только друзья) → **Save Changes**.

Готово: игру может найти и запустить любой игрок 16+.

## Шаг 9 (необязательно). Аудитория всех возрастов
Требования Roblox:
- полная анкета Maturity & Compliance с итогом Minimal, Mild или Moderate;
- верификация **по паспорту** (с 18 лет);
- включённая **двухэтапная проверка**;
- плата: **1 000 Robux** (возвращаемые) **или** подписка Roblox Plus/Premium, активная 2 месяца подряд;
- оценка игры Roblox: **250 уникальных заходов** «вовлечённых» игроков 16+ за 60 дней.

Плата — это покупка Robux. Плюс неизвестно, доступна ли верификация по паспорту в Беларуси. Поэтому для хобби-проекта **рекомендую остановиться на 16+**.

Если всё же пойдёшь сюда, честные ответы для анкеты:
- насилия нет: потеря сознания от холода — не насилие;
- страх: тревожная атмосфера бурана без хоррора, ближе всего «мягкий»;
- крови, грубого юмора, азартных игр, мата нет;
- социальной зоны нет;
- главная тема — не «острая общественная проблема».

## Шаг 10. Обновления после релиза
1. Скачай исправления: `git pull`.
2. Открой облачный place: Creator Hub → **Edit in Studio**.
3. Запусти `rojo serve`, в Studio нажми **Connect**.
4. Проверь в Play.
5. **File → Publish**.
6. Если менялись `Heightmap` или `Level` и рельеф был «запечён», увеличь `Config.TerrainVersion` и запеки заново (шаг 6).

Каждое обновление снова проходит требования к релизу (шаг 8). Если изменилось содержание игры, ответы анкеты нужно обновить.
