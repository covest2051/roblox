# Плейтест «Перевала»: что проверить и как дать обратную связь

Займёт 30–40 минут. Делай по порядку: сначала проверь, что всё запускается, потом пройди уровень честно, потом добей отдельные места через отладку.

## 0. Запуск (5 мин)
1. Скачай обновления и собери place:
   ```powershell
   git pull
   rokit install
   rojo build -o game.rbxl
   ```
2. Открой `game.rbxl` в Studio.
3. Открой **View → Output**: там будут ошибки и самотест.
4. Нажми **Play** (F5).

**На что смотреть:**
- [ ] Экран «ПЕРЕВАЛ» и проценты, затем интро. Сколько секунд шла загрузка?
- [ ] В Output нет красных строк.
- [ ] Через ~5 с после старта появляется `[SELFTEST] RESULT N/N passed`. Если есть `FAIL` или `WARN`, скопируй эти строки.

> Если загрузка длится больше 20 с, можно «запечь» рельеф (см. `LOCAL_SESSION.md`).

## 1. Честное прохождение (15 мин)
Не пользуйся панелью DBG. Играй так, как играл бы новичок.

| Этап | Проверь |
|---|---|
| Интро | Читается ли текст? Понятно ли, что это Перевал Дятлова и что события вымышлены? Пробел пропускает? |
| Палатка | Видны ли 5 вещей? Удобно ли брать (E)? Понятно ли, что взять можно только 3? Хватает ли 35 секунд? Персонаж не застревает под скатом? |
| Разрез | Подсказка «Разрезать» на стенке видна? После разреза можно выйти? |
| Склон | Видны ли красно-белые вешки? Видны ли фонари ребят впереди? Предупреждение о порыве успевает? Камни реально укрывают (статус «Укрытие»)? **Не слишком ли темно?** |
| Кедр | Костёр горит? Записка читается (E)? Согреваешься? |
| Лес | Хворост легко найти? «Огни в небе» случились? Как выглядят? Костёр на стоянке разжёгся? |
| Овраг | Видно разницу тёмного (тонкого) и светлого льда? Проваливаешься в тонкий? Получается вылезти из ручья? Брёвна проходимы? |
| Поляна | Белая мгла не перебор? Стрелка «колокол» помогает дойти? |
| Изба | Вход засчитался? Финальные тексты читаются? Кнопка «Пройти ещё раз» работает? |

**Запиши:**
- общее время (покажет финальный экран);
- сколько раз терял сознание и где;
- где было скучно, где непонятно, куда идти, где слишком легко или тяжело.

## 2. Точечные проверки через DBG (10 мин)
Кнопка **DBG** справа сверху.
- [ ] «→ Ravine creek»: тонкий лёд проламывается, мокрая одежда сушится у костра.
- [ ] «Heat = 10»: появляется иней по краям, потом потеря сознания и возврат к костру.
- [ ] «God mode» + пробежка по склону: нет ли дыр в рельефе, «швов», висящих объектов?
- [ ] «RU / EN»: оба языка читаются, текст не вылезает за рамки.
- [ ] Shift (бег), F (фонарь, если брал), Q (термос, если брал).

## 3. Производительность (2 мин)
- **View → Stats** или **Ctrl+Shift+F5**: какой FPS в лесу и на поляне?
- **Ctrl+F6 (MicroProfiler)**: только если FPS ниже 40.

## Как прислать обратную связь
Скопируй шаблон, заполни и пришли в облачную сессию (до 4 ноября) или в локальную:

```
Загрузка мира: __ с
SELFTEST: (вставь строки с FAIL/WARN, если есть)
Ошибки Output: (вставь красные строки целиком)

Время прохождения: __:__   Потерь сознания: __ (где: ...)
Вещи, которые брал: ...

Темнота/видимость: слишком темно / нормально / слишком светло
Метель на поляне: перебор / нормально / мало
Сложность склона: легко / нормально / тяжело
Понятно ли, куда идти: да / нет (где терялся: ...)

Баги (что делал → что ожидал → что случилось):
1.
2.

Что понравилось / что скучно:
FPS в лесу: __
```

Скриншоты особенно полезны для: темноты, «швов» рельефа, висящего льда, палатки изнутри.
